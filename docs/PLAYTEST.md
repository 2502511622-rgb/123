# v0.8：玩家实际操作与战斗成长验证

新增 58 项规则检查和 47 项键鼠玩家操作检查；完整回归共 371 项。图形模式另外复跑同一套 47 项玩家操作，并审查真实运行截图。

玩家流程使用两组准备场景：第 3 日二级角色（300 文、基础弹药与经营材料），用于来信、村庄、交易、技能学习和救援；第 9 日四级角色（T2 灵纹步枪与备用弹药），用于满生命强化棺中客。没有在实战中直接扣敌人生命或冻结敌人；控制只通过键盘移动、攻击、装填、闪避和 GUI 点击。最后的词条验证使用固定高生命靶子，单独检查暴击和持续伤害。

操作路径：K 读信 → 步行 E 进村 → 沿街找铁匠 → 购买步枪与弹药 → B 穿戴主武器 → 滚轮切换三栏 → I 技能树学习符火 → U 装填 → 步行返回义庄 → T 等入夜 → E 回村救援 → 鼠标方向对应瞄准、持续射击、装填和 Shift 躲避 → 村民实际受击且救援成功 → 走到尸体 V 炼化 → H 训练并确认解散 → 满生命强化 Boss 实战 → V 炼化 Boss → 随从被真实敌弹打伤、倒下、疗养、重新出战 → 穿戴页实际铭刻双词条 → 弹丸触发暴击和重伤 → 确认停止射击后仍有持续伤害 → 实际存档恢复。

试玩发现并修复：村民小范围巡走后互动距离不一致；新村庄换场景错误切回农具导致无法射击；角色页穿戴与铭刻按钮文字相近导致旧测试点错按钮；敌人攻击触发玩家倒下换场景后仍调用旧物理空间。补充敌人绕障追击与视线判断，避免 Boss 被障碍挡住后不停空打。

平衡验证使用一千次普通掉落样本、三百次精英样本和一千次词条攻击抽样，核对装备更稀少、枪械更稀有、弹药稳定、材料常见；同时核对技能点与前置、充能上限和恢复、随从出战上限、Boss 炼化削弱、升级继承、重复救援领奖保护及旧存档迁移。

音频在自动试玩中关闭。以上是软件渲染与自动键鼠驱动的功能试玩，尚不代表真人一小时以上的难度与节奏评价。

# v0.5 玩家流程与画面检查

本次以新玩家的操作顺序设计键鼠驱动试玩，使用 Godot 的 GUI 鼠标事件分发、键盘事件和持续移动输入。它是自动模拟试玩与截图审查，不代表真人长时间游玩的主观评价。

## 实际操作路线

标题中新建义庄 → 鼠标收起遗书 → 从田边走到义庄 → E 进入 → 仓箱存取界面 → 门口退出 → 穿过农田左侧入口 → 1/2/3 配合空格翻土、播种、浇水 → I 打开行囊 → 关闭后绕田、过桥 → E 进入乱葬坡 → F 压制活敌 → J 击杀 → E 查看遗骸并点击装车 → 减速载骸返回 → 跨桥回义庄 → 案台处理运输车 → 滚动界面并点击炼为役灵。

这条流程使用实际移动与互动，没有用场景跳转、直接修改生命或直接调用炼化方法代替操作。后面的墙体、背后攻击、接触帧与闪避检查使用明确摆放的测试场景。

## 发现并处理

| 问题 | 修改 |
| --- | --- |
| 义庄门边纸灯挡住横向通行 | 将纸灯移出门口路线，保留建筑和河道实体碰撞 |
| 命息、资源混在一行小字中 | 独立命息与气力条，资源和时辰集中在右上角 |
| 默认进度条的最小高度挤住第二条 | 用固定尺寸像素状态条替换 |
| 近战判定能扫到视觉剑弧之外 | 统一 49 像素范围与前方扇区，背后敌人不受伤 |
| 符术与敌人攻击可跨墙命中 | 结算前检查实体墙遮挡，遮挡符术不消耗符箓 |
| 按键瞬间扣血，缺少接触过程 | 0.06 秒起手后结算；一次挥剑不重复命中，菜单暂停待结算攻击 |
| 敌人、玩家可随意穿过彼此 | 增加身体碰撞；闪避期间允许穿过敌人，墙体保持阻挡 |
| 夜战反馈不明确 | 增加伤害数字、像素碎屑、符术轨迹、闪避残影和蓄力圈进度 |
